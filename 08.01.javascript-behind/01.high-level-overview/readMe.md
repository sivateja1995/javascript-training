# High Level Overview 
| Feature | Description |
| --- | --- |
| High level | JavaScript provides abstractions that simplify development. |
| Garbage collection | JavaScript automatically manages memory by reclaiming unused values. |
| Interpreted or JIT | JavaScript engines can interpret code and use just-in-time (JIT) compilation. |
| Multi-paradigm | JavaScript supports multiple programming styles, including procedural, object-oriented, and functional. |
| Object-oriented | JavaScript supports object-oriented programming using objects and prototypes. |
| First-class functions | Functions can be stored in variables, passed as arguments, and returned from functions. |
| Dynamic | Types are determined and checked while the program is running. |
| Single-threaded | JavaScript executes one task at a time on its main thread. |
| Non-blocking | JavaScript delegates asynchronous work to avoid blocking the main thread. |
